# Multi-Step-Student-Application-Form
Project Description
This project is a responsive, multi-step student application form created using HTML, Bootstrap, and JavaScript. It allows a user to enter their personal profile information, academic history, and upload necessary documents in a structured, three-page layout. The form includes client-side validation to ensure data integrity before submission.

Features
Multi-Page Structure: The application is divided into three logical sections for a better user experience:

Profile: Captures personal details, contact information, and addresses.

Academic: Records previous examination details and qualifications.

Documents: Allows for the upload of a photograph, signature, and other required proofs.

Address Autofill: Includes a "Same as permanent address" checkbox to automatically populate the mailing address fields, saving user time.

Client-Side Validation: Implements JavaScript-based validation for various fields, including:

Email format validation.

Mobile number validation (accepts only 10-digit numbers).

Name fields that only accept alphabetic characters.

File type and size validation for document uploads (accepts only .jpg, .jpeg, .png up to 5MB).

Responsive Design: Utilizes the Bootstrap framework to ensure the form is usable across different screen sizes, from desktops to mobile devices.

Clear Navigation: "Next" and "Previous" buttons allow users to easily navigate between the different sections of the form.

Technologies Used
HTML5: For the structure and content of the web pages.

CSS3: For custom styling and layout enhancements.

Bootstrap 5: For the responsive grid system, styling of form components, and overall design.

JavaScript: For client-side form validation and interactive features like the address autofill.

How to Run This Project
This is a static web project and does not require a server to run.

Download the Files: Make sure you have all the project files in a single folder:

Profile.html

Academic.html

Documents.html

The bootstrap-5.3.2-dist folder (or ensure the Bootstrap CSS and JS links are valid).

Open in Browser: Open the Profile.html file in any modern web browser to start the application process.
